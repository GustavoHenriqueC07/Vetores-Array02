# Vetores-Array02
# Exercícios de Vetores em JavaScript

## Descrição

Este projeto reúne exercícios desenvolvidos em JavaScript com o objetivo de praticar conceitos fundamentais da linguagem, como:

* Vetores (Arrays)
* Estruturas de repetição (`for`)
* Estruturas condicionais (`if`)
* Entrada de dados com `prompt()`
* Saída de dados com `alert()`
* Manipulação e análise de dados armazenados em vetores

---

## Exercícios Desenvolvidos

### 1. Exibição de Nomes em Ordem Inversa

O programa solicita 7 nomes ao usuário, armazena-os em um vetor e, ao final, exibe todos os nomes na ordem inversa da digitação.

**Conceitos trabalhados:**

* Arrays
* Laços de repetição
* Percorrer vetores de trás para frente

---

### 2. Média de Valores e Filtragem

O programa lê 8 números reais, calcula a média dos valores armazenados e exibe apenas os números que estão acima da média calculada.

**Conceitos trabalhados:**

* Soma de elementos de um vetor
* Cálculo de média aritmética
* Filtragem utilizando condições

---

### 3. Cadastro de Pessoas Menores de Idade

O sistema lê o nome e a idade de 9 pessoas, armazenando os dados em dois vetores relacionados. Ao final, exibe apenas os nomes e idades das pessoas menores de 18 anos.

**Conceitos trabalhados:**

* Vetores paralelos
* Estruturas condicionais
* Relacionamento de dados por índice

---

### 4. Interseção entre Vetores

O programa lê dois vetores contendo 5 números inteiros cada e gera um terceiro vetor contendo apenas os elementos que aparecem em ambos os vetores, sem repetições.

**Conceitos trabalhados:**

* Comparação entre vetores
* Busca de elementos
* Eliminação de valores repetidos
